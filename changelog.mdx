## Upgrading Your Instance

<Steps>
  <Step title="Backup Data" icon="database">

    Create a full backup before proceeding.

````bash
cp -r /path/to/lodestone-data /backup/location
````

  </Step>
  <Step title="Update Package" icon="download">

    Use your preferred package manager.

    <CodeGroup tabs="npm,yarn">
````bash
npm install lodestone-docs@latest
````
````bash
yarn add lodestone-docs@latest
````
    </CodeGroup>

  </Step>
  <Step title="Run Migrations" icon="settings">

    Execute database migrations.

````bash
npx lodestone migrate
````

  </Step>
  <Step title="Restart Service" icon="refresh-cw">

    Restart your Lodestone instance.

````bash
systemctl restart lodestone
# or
pm2 restart lodestone
````

  </Step>
</Steps>

<Callout kind="alert">
  For v1.0.0 upgrades, review breaking changes and test in staging first.
</Callout>

## Migration Guide

<Tabs>
  <Tab title="From v0.x to v1.x" icon="arrow-up">

    Update your config to use new endpoints.

````javascript
// Old
const apiUrl = 'https://api.example.com/v0/clarity';

// New
const apiUrl = 'https://api.example.com/v1/clarity';
````

  </Tab>
  <Tab title="Config Changes" icon="settings">

    Replace deprecated options.

    <ParamField path="lenses" param-type="array" required="true">
      Array of active lenses: `["marketing", "innovation"]`.
    </ParamField>

    <ParamField body="flowEnabled" param-type="boolean" required="false">
      Enable FLOW tracking. Defaults to `false`.
    </ParamField>

  </Tab>
</Tabs>
