## Document Creation and Editing

Start new documents quickly for project proposals, consulting reports, or MIND/FLOW™ analyses. The editor supports rich markdown, including headings, lists, and embeds.

<Steps>
  <Step title="Create a New Doc" icon="plus">
    Navigate to your project space and select `New Document`. Choose a template or start blank.
  </Step>
  <Step title="Edit Content" icon="edit-3">
    Use the markdown editor for structured content. Preview changes in real-time.

````markdown
## Project Overview

**Client:** Acme Corp  
**Objective:** Achieve 20% growth via MIND/FLOW™

- Marketing audit complete
- Innovation pipeline identified
````

  </Step>
  <Step title="Publish" icon="upload-cloud">
    Save and publish to share with your team or clients.
  </Step>
</Steps>

<Callout kind="tip">
  Enable auto-save to prevent data loss during long editing sessions.
</Callout>

## Collaboration and Permissions

Invite team members or clients to collaborate securely. Assign roles like Viewer, Editor, or Admin.

<Tabs>
  <Tab title="Team Member" icon="user">

  </Tab>
  <Tab title="Client Access" icon="shield">

  </Tab>
  <Tab title="Admin" icon="settings">
    Manage permissions and project spaces.
  </Tab>

## Version History

Every change creates a version snapshot. Compare diffs and restore previous states.

<Expandable title="View Version Details" default-open="true">
  Access history via the `Versions` tab. Select a version to preview:

  ```
  v1.2 - Added growth metrics (2024-10-15)
  v1.1 - Initial draft (2024-10-10)
  v1.0 - Created (2024-10-08)
  ```

  Rollback with one click.
</Expandable>
