## Overview

To begin using Lodestone Consulting Ltd's documentation space:

1. Sign up at `https://dashboard.lodestoneconsulting.com`.
2. Create your organization or join an existing one.
3. Add your first project or select a template.
4. Start building your documentation in an intuitive editor.

## Access

Invite your team members for collaboration:

- Go to Team Settings > Invite
- Add their email addresses
- Assign roles (Admin, Editor, Viewer)

You're ready to organize and manage your project docs efficiently!
